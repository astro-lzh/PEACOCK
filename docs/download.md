# Software releases

Use this page to retrieve a particular version of PEACOCK. For a first installation,
[download the current version and set up your computer](installation.md).

(source-download)=
## PEACOCK 1.0.3

{download}`Download PEACOCK 1.0.3 source (ZIP) <assets/PEACOCK-1.0.3.zip>`

The download includes the source code and examples. The C II tutorial uses a lower-level population ratio of $n_2/n_1=0.1$.

See [Citing PEACOCK](citing.md) for the software and paper references.

## Earlier versions

{download}`PEACOCK 1.0.2 source (ZIP) <assets/PEACOCK-1.0.2.zip>` contains the C II tutorial with $n_2/n_1=0.3$.

{download}`PEACOCK 1.0.1 source (ZIP) <assets/PEACOCK-1.0.1.zip>` contains an earlier tutorial configuration.

The original **PEACOCK 1.0** is preserved on
[Zenodo](https://doi.org/10.5281/zenodo.24206426). This DOI identifies the original 1.0
archive, which predates the current tutorial inputs and plotting helper.
